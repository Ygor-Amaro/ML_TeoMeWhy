# Curso de Machine Learning
## Como ensinar a máquina com o professor Téo Calvo

### aula 01 - Introdução ao Machine Learning

- Dados são importantes para embassar a tomada de descições, usando informações (materialidade) ao invés de tomar uma descição com base em achismo (feeling)

### Possibilidades em dados (alguns exemplos de uso de dados no dia a dia):
- previsão de vendas;
- tempo de garantia;
- limite de crédito;
- manutenção de equipamentos industriais;
- recomendação de produtos;
- definição de metas;
- processamento de linguagem natural;
- segmentação de clientes;
- validar produtos com usuário (UX);
- entender sazonalidade;
- visão computacional;
- perfomance de atletas;
- eficácia de vacinas e medicamentos;
- analises preditivas.

### Profissionais de dados:

- Engennharia de dados:
    É responsável por coletar os dados de diferentes fontes e disponibiliza-los para que outros possam consumir esses dados, tornando o acesso ao dado mais simples e ter os dados tratados, com qualidade, governança, taxonomia, infraestrutura, desenvolvimento de pipelines, deploy e disṕnibilidade 24/7.

- Analise de dados:
    Consumir os dados (de preferencias já tratados e organizados pelos engenheiros de dados) e aplica-los orientados ao negócios, focado em entender o passado e o presente.

- Ciência de dados:
    Consumir os dados e aplica-los para análises preditivas, focado em tentar prever o futuro.
